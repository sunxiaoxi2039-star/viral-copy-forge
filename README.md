# viral-copy-forge · 爆款文案锻造坊

> 给它一个产品、一个对家，再喂一批这个品类在小红书、抖音上正在火的笔记，它交回一套能直接发的种草文案。每个钩子后面都挂着来源笔记和赞数，链接点得开。
>
> 适用 Claude Code；其他能读 `SKILL.md` 格式的 agent 也能装。流程脚本只要 Python 3.8+，不要密钥。

**同题盲评 45.0 分**（满分 60），同类开源 skill 28.2，不用 skill 29.0。评委是两家不同的模型，看不到署名。[怎么考的 ↓](#凭什么信它)

## 它帮你解决什么

- 不知道这个月哪个标签真在涨赞 → **按点赞给标签排座次**。一条百万赞爆款不许带飞整张表，样本不够就自动降级，不冒充实测。
- 卖点写出去才发现违规 → **合规台账逐条判**：能用、待补、驳回。没证据的卖点进不了标题。
- 写出来一股模板味，换个牌子照样成立 → **换品名测试**。换了还成立的句子作废重写。
- 甲方问「为什么这么写」答不上来 → **每句都有证据行**：学的是哪几条爆款、各多少赞。

## 一个真实案例：防脱洗发水

2026-09-19，喂进去蔓迪防脱固发洗发水、两个对家（达霏欣、卡诗），外加真实采集的小红书 50 条、抖音 20 条。

它交回来的主推标题：

> **发缝第 28 天｜我把每周一张的照片按顺序排了出来**

句式学自一条 1,514 赞的笔记，放行条件写在旁边：发帖人手里真有 28 天的周拍照片，否则整条作废。

更能说明它脾气的，是它**拒绝写**的三样东西：

- **「5% 米诺地尔」驳回。** 这是药品成分，洗发水按化妆品管，这句一写就越线。
- **「械字号」待补。** 没有备案号截图之前，一个字不进文案。
- **抖音整表降成观察级，主表空着交。** 20 条视频一条发布日期都没抓到，看不出新旧。连 179.7 万赞那条所在的话题也只挂了 4 条视频，进了弱证据附录。宁可交白卷，也不凑一个第一名。

完整产物都在仓里，谁都能点开核对：[火力表](examples/out/fire-table-2026-09-19.md)、[文案包](examples/out/copy-package-2026-09-19.md)、[原始数据](examples/data)。

## 怎么用：直接跟 agent 说

| 你说 | 它做什么 |
|---|---|
| 「帮我给 XX 写小红书种草，对标 YY」 | 跑完六段：校准产品卡 → 采集 → 拆竞品 → 标签火力表 → 写稿 → 质检，交整套文案包 |
| 「XX 这个品类，小红书哪些标签在火？」 | 按点赞排出标签火力表，样本不够的单独放进弱证据附录 |
| 「给 XX 写一条抖音带货口播」 | 前 3 秒钩子单独写，抖音话题池只用过了闸门的 |
| 「把这段英文文案翻成中文」 | **不触发**。没有竞品和标签数据的活，交给润色类 skill |

笔记数据要用你自己的采集工具或已登录的浏览器抓进来（本仓不带采集脚本）。手抄 20 到 30 条也能跑，样本不够时它会自动降级。安装 3 步，见下面[安装](#安装)。

## 适合谁

- **自己开店、自己写种草的老板**：请不起代运营，也没空每天刷两小时同行。
- **代运营和 MCN 的文案**：一天出十几个品，每篇都要能跟甲方讲清楚「为什么这么写」。
- **品牌方的内容负责人**：投放之前，想先看清这个赛道真实的点赞分布，而不是听人说「这个很火」。

## 你拿到的是什么

| 交付物 | 长什么样 |
|---|---|
| 标签火力表 | 这个品类每个标签有几条爆款、加权赞多少、样本够不够；样本不够的单独放进弱证据附录，不混进主表 |
| 1 条主推标题 | 带数字锚点，品牌名换成别家就不成立；另附四道自检的打分 |
| 小红书正文 | 干净成稿，复制就能发，句子里不夹任何写法注解 |
| 抖音口播 | 前 3 秒钩子单独写 |
| 标签双池 | 小红书一池、抖音一池，主钩子标签必须过火力闸门 |
| 证据行 | 每一句用了哪种写法、学的是哪几条爆款、各多少赞 |
| 合规台账 | 你给的每个卖点逐条判：能用、待补、驳回，理由写在旁边 |

## 凭什么信它

**2026-09-21 同题盲评。** 三道题：防脱洗发水、儿童有机棉内衣、冻干猫粮，喂的全是真实采集的笔记；每张产品卡里故意埋一个没证据的卖点，看谁会把它写进标题。三份卷子用同一个写手模型，只换 skill。两家不同的评委模型打分，看不到哪份是谁写的，但能对照原始材料查数字。

| 3 题 × 2 评委，每格满分 60 | 本 skill | 同类开源 skill | 不用 skill |
|---|---|---|---|
| 平均分 | **45.0** | 28.2 | 29.0 |
| 合规与风险 | **7.7** | 3.7 | 2.5 |
| 真人味 | **7.5** | 4.5 | 6.2 |

埋雷那一项：有机棉那题的产品卡写着「39℃ 恒温、比普通棉暖 3 倍」，没有检测报告，驳回。写手把它改成「39℃ 恒温科技」塞进标题，照样被拦下，还标出在第几行。（这道拦截是盲评中途发现漏洞后补上的，前两次重跑没拦住，经过也写在下面的链接里。）

样本只有 6 格，也有评委在某一题更喜欢我们上一版的卷子。这些都照实写在 [docs/RESULTS.md](docs/RESULTS.md)。

**跟同类比**：同类项目不少，有的比我们全，比如 [social-account-doctor](https://github.com/JuneYaooo/social-account-doctor)（五个平台，自带采集）、[lingzao-skill](https://github.com/atian-create/lingzao-skill)（带公众号）、[viral-note-agent-skill](https://github.com/xuboboo/xiaohongshu-viral-note-agent-skill)（从选题一路做到发布复盘）。我们只做窄的一件事：**按点赞给标签排火力，样本不够就自动降级，一条爆款不许带飞整张表**；再加一道硬规矩，没证据的话一个字都不进文案。完整对照见 [docs/RESULTS.md](docs/RESULTS.md#竞品对照)。

## 5 分钟跑一遍（不用装 skill，也不用模型密钥）

仓里带了 2026-09-19 真实采集的一份数据和它跑出来的全部产物，`git clone` 后直接复现：

```bash
# 1. 从采集数据算火力表（小红书 50 条 + 抖音 20 条）
python3 viral-copy-forge/scripts/fire_table.py \
    examples/data/xhs-2026-09-19.json examples/data/douyin-2026-09-19.json \
    --asof 2026-09-19

# 2. 把产出的文案包过一遍出厂扫描（⑥段里机器能判死的部分）
python3 viral-copy-forge/scripts/lint_package.py \
    examples/out/copy-package-2026-09-19.md --observational

# 3. 看用例清单，并让机器判一遍你自己的成品
python3 viral-copy-forge/evals/run_evals.py --case case1-mandi-anti-hairloss \
    --package examples/out/copy-package-2026-09-19.md --observational

# 4. 闸门一致性 + 出厂扫描的测试（纯标准库，无依赖）
python3 tests/test_gates.py && python3 tests/test_lint.py
```

你自己的数据怎么喂进来：CSV 或 JSON 先过 `scripts/normalize.py`，格式契约见 [docs/DATA_SCHEMA.md](docs/DATA_SCHEMA.md)。

## 六段流水线

```
①输入与校准 → ②双平台采集 → ③竞品属性解剖 → ④标签火力实证 → ⑤组合生成 → ⑥质检与交付
```

第 ④ 段是核心差异化：不靠感觉判断「什么标签会火」，靠**同类目/竞品笔记的累计点赞排序**——小红书看笔记赞，抖音看话题下所有视频的累计赞。方法不神秘，四步：**搬数据、提标签、拆竞品、重组生成**——流程图上没有一步是魔法，谁都能装。

内置六道质量闸（这是它和「模板生成器」的区别）：

| 闸 | 拦什么 |
|---|---|
| 换品名死亡测试 | 换个牌子句子还成立 = 品类通用句，作废重写 |
| 刺点配额 | 每条标题必须含 1 个产品卡里的不可公式化元件，禁用「有图有真相」类万能补丁 |
| 样本闸 | 单平台样本不足、或过半样本连发布日期都没有时，火力表降级为「观察级」，不宣称实证 |
| 离群封顶 | 一条百万赞爆款不许带飞整张火力表 |
| 记忆点不可互换 | 竞品记忆点贴到你的产品上要「别扭」才算数 |
| 出厂三问 | 换品名复测 + 来源可点 + 平庸检测，全过才交付 |

## 安装

1. 把 `viral-copy-forge/` 整个文件夹放进 `~/.claude/skills/`（或你项目的 `.claude/skills/`）。
2. 确认 `SKILL.md` 在该文件夹根目录——加载器靠它的 `description` 决定什么时候自动装载，不用手动 `/load`。
3. 在会读 `SKILL.md` 的环境（Claude Code 及兼容加载器）里，说一句「帮我写个爆款文案」或「给 XX 产品 tag 一下小红书热标签」，它会自己触发。

`scripts/`、`tests/`、`evals/` 只要 Python 3.8+，无第三方依赖，不装 skill 也能单独用。

> **采集工具要自备**：本仓只有流程和规则，不带任何采集脚本。小红书和抖音的数据都要靠你自己的采集工具（比如 [All-IN-ONE](https://github.com/cv-cat/All-IN-ONE) 或已登录的浏览器会话）喂进来，否则第②段会卡住。抖音没有官方 API，首次用请看 `references/douyin.md` 里的边界说明。

## 它不做什么

- **不是自动发布机器人**——生成完文案不会帮你发出去，自动发布接线只有可选说明，默认关。
- **不是投放/出价优化工具**——点赞是「这个标签曾经有人看」的代理指标，不等于你投出去的 CTR/CVR，钱要自己去投放台测。
- **不是纯润色或纯翻译工具**——没有竞品数据和标签火力表介入的场景（比如你只是要把英文文案翻成中文），这个 skill 不该触发，用别的润色类 skill。
- **不是学术写作或严肃文档助手**——它天生带营销腔和情绪钩子，写论文别找它。
- **不保证防编造**——Claim Ledger（证据台账）只在功效、母婴、食品类强制开，其他品类默认关；开着也只是提醒你核对，别拿它当免责声明生成器。

## 三句丑话

1. 标签组合不保证巨大流量——它只是把「被验证过有人看的词」装进你的笔记，起跑线从 0 分提到 60 分，剩下 40 分靠内容和投流的钱。
2. 平台会查重，句式可以借，内容必须换皮。
3. 抖音这半边通道不如小红书稳，装之前先看清楚边界说明。
