## 1. 数据分级（每批数据标口径）

| 级别 | 含义 | 用法 |
|---|---|---|
| PUBLIC_INDEX | 公开搜索可见的笔记与点赞 | 默认口径 |
| AUTHORIZED | 账号主人自己导入的后台数据 | 仅用户主动提供时用 |
| ESTIMATED | 按规则估算的数字 | 必须标「估算」，不与实数混排 |

登录态通道（你本机安装的浏览器会话采集工具 / All-IN-ONE CLI 等）比纯公开搜索看得更深，但属灰色通道：用前提示用户，尊重平台规则，不做高频硬爬，不碰发布类接口。

## 2. 搜索词构造

- 品类词：产品所属品类大词（如「防脱洗发水」「有机棉童装」）。
- 竞品词：每个竞品名单独搜一轮。
- 后缀词表（跨品类通用）：教程 / 推荐 / 分享 / 测评 / 攻略 / 合集。
- 先抓 20 条试跑，字段齐再放量；样本三档 30 / 50 / 80，预算少就 30。

## 3. 采集字段（缺了记 null，不当 0）

| 字段 | 说明 |
|---|---|
| title | 标题原文 |
| hook | 开头第一句（进正文才有） |
| likes | 点赞数（火力实证的主指标） |
| collects | 收藏数（收藏型品类的辅助信号） |
| tags | 话题标签组 |
| author / author_type | 博主名与类型（医生/素人/品牌号） |
| date | 发布日期（算标签时效） |
| url | 原链接（证据可回溯） |

只有标题+赞数的列表数据不够做解剖：爆款要进正文抽 hook 与结构，深度分析必须正文。

## 4. 爆款线与样本门槛

1. 算本批样本的中位赞（只算有可见赞的）。
2. 爆款线 = 3 × 中位赞。
3. 爆款 ≥5 条才够出火力表；不够就写「样本不足：仅验证 N/30 条」，降级为只出解剖、不出火力结论。
4. 单平台有效样本 <20 条：火力表整表标「观察级」，禁用「实测最火」表述；提示用户补 3-5 个竞品名扩样，拒绝则交付物挂「样本不足」徽章。
5. 标签最小样本闸：主火力标签需 ≥8 条含该标签的笔记；不够 → 只进「弱证据附录」，禁当第⑤段主钩子。
6. 离群封顶：单条赞 > 同池中位数 10 倍，按 10×中位数计入累计；话题累计赞若单条贡献 >70%，不得标「品类主火力」，只能标「单条爆款句式，可借结构不可借权重」。
7. 中位数为 0（多数没赞）时停用 3× 规则，直接取 TOP10 按赞排序解剖，并标注口径。
8. 火力计算默认只计近 90 天互动；有按周粒度数据时用按周指数衰减加权。标签累计赞 < 类目 2 倍中位赞的，只进备选池，不进主推位。

## 5. 标签归一与入库

- 同义标签并账再统计（#早八人 与 #早八 是一个标签）。
- canonical + aliases 两级：平台规范话题做 canonical，变体写法映射过去。
- 入库门槛：≥2 条爆款出现为「实证档」；1 条但赞高为「孤证档」（可参考不强推）。
- 每篇挂 5-8 个：1-2 个领域标签 + 1 个类型标签 + 0-1 个热点标签。

## 6. 标题与正文口径

- 核心词落标题前 10-12 字。
- 正文前段自然出现主词 2-3 次，不堆砌。
- 清单/对比/边界类内容可收藏性强，优先选这类结构。

## 7. 评论区挖掘（可选加分项）

爆款笔记评论区 8 类：疑问 / 痛点 / 异议 / 经验分享 / 身份认同 / 购买意图 / 要资源 / 作者引导转化。高频疑问与异议直接变成新文案的 FAQ 与反转点素材。

## 8. 标签时效

每个标签记「最近实证日期」；超 90 天无新爆款实证的降权标注，不删除（防误删季节性/周期性标签）。
