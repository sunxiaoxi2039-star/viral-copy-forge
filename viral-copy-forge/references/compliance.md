## 1. 极限词与绝对化用语（出现即改）

最 / 第一 / 顶级 / 极致 / 绝对 / 100% / 国家级 / 全网最 / 史上 / 独家 / 首个 / 彻底 / 根治 / 永久 / 无效退款。

改写方向：换成可验证的具体事实（「抑菌率 99%」必须有检测报告背书；没有就删，不许软化成「可能」继续用）。

## 2. 医疗与功效红线（分品类）

- 普通化妆品：不得宣称医疗作用（生发/育发/脱毛/治疗 X）。防脱属特殊化妆品，须持特证；没证就只说「固发防断发」「强韧」。
- 械字号/特证产品：只说批文范围内的宣称；红线示例「不宣称生发」「不对比未验证人群」。
- 医生/专家背书：必须有真实依据。「医生朋友说」这类人格化背书不得指向虚构的具体机构或头衔；无真实依据时降级为「学成分的朋友」「学药的朋友」类普通人格。
- 母婴：不制造恐吓焦虑（「不买就害了孩子」式表达禁）；认证编号必须真实可查，查不到就挂待补。
- 竞品：不点名、不影射攻击竞品（「养发的尽头不是姜」这类影射句过闸要改）。

## 3. 平台限流与导流

- 正文不出现站外导流（微信号/VX/「私信我领 XX」→ 移到评论区置顶或主页，按各平台口径）。
- 抖音敏感词：夸大功效、绝对化、医疗词最先限流；过不了审的词换口语替代表述。

## 4. Claim Ledger（证据台账）

表模板：

| # | 声明 | 类型 | 证据 | 来源 | 状态 |
|---|---|---|---|---|---|
| 1 | （产品卖点/承诺原文） | 成分/效果/认证/价格 | （检测报告/批号/实拍） | （可回溯来源） | ✅已验证 / ⚠️待补 / ❌无证据 |

规则：
- 每个产品卖点声明一行。
- ❌（无证据）的声明直接删，不许软化成「可能 / 据说 / 很多人反馈」继续用。
- ⚠️（待补）的标出来，写进交付的数据缺口声明，发布前必须补齐。
- 默认关；医疗/功效/母婴/认证类强制开；用户点名也开。

## 5. 人味终检（8 类 AI 腔反查）

三段式套话（首先/其次/最后） / 库存转场词（值得注意的是/综上所述） / 无出处权威（专家表示/研究表明） / 膨胀形容词（赋能/打造/助力/惊艳） / 空洞对仗（既…又…） / 通用开头结尾 / 列表腔 / 翻译腔。

改写方向：换具体名词、换主动动词、长短句交替、首句直接开场。

黑话禁词一并扫：赋能 / 抓手 / 闭环 / 底层逻辑 / 打法 / 拉通 / 沉淀 / 颗粒度 / 对齐 / 链路 / 组合拳 / 心智 / 范式。

## 6. 出厂扫描顺序与修复上限

极限词 → 医疗越线 → 导流 → 竞品攻击 → AI 腔 → 效果闸出厂三问（换品名 / 来源可点 / 平庸检测，见 SKILL.md ⑥） → 人格声音抽检。

自动修复最多 3 轮，只改失败项；改不完的部分如实标注交付，不假装通过。效果闸一票否决回⑤；⑤重写两轮仍不过回③补记忆点，不准靠润色蒙混。

## 7. 分品类强制矩阵

| 品类 | 违禁词扫描 | Claim Ledger | 特别红线 |
|---|---|---|---|
| 普通日用品 | 默认开 | 默认关 | — |
| 化妆品/功效类 | 默认开 | 强制开 | 特证宣称范围 |
| 医疗器械/药品相关 | 默认开 | 强制开 | 不宣称治疗/生发 |
| 母婴 | 默认开 | 强制开 | 不恐吓 + 编号可查 |
| 食品/保健品 | 默认开 | 强制开 | 不作替代药物的表述 |
