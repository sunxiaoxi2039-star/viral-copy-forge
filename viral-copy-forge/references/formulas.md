**竞品记忆点五问**（对每个竞品整体问一遍）：

1. 产品形态：它卖的是「什么」？（实证：卡诗不卖洗发水，卖「头皮精华」——换品类词拉客单）
2. 卖点昵称：成分/卖点有没有外号？（实证：「元气姜」2029 赞——有昵称好传播）
3. 使用仪式：它让人怎么用？（实证：打卡 day1→day28 连载，417+150 赞——逼真又养成复购）
4. 信任装置：靠什么让人信？（空瓶日记 / 检测报告 / 批号可查 / 医生出镜 9725 赞）
5. 人群细分：它说给谁听？（实证：「细软油头」——越具体越像真推荐）

**空位识别**：把五问的答案横向一摆——竞品都做了什么、都漏了什么。没人做的那格，就是用户产品的钩子候选。实证：童装竞品全在晒检测报告，无人让「认证编号可查」——空位即差异化钩子。

**三分法过滤**：
- 可迁移：钩子/结构/CTA/标签配法/说服顺序 → 直接拿走
- 需改造：语气/案例/受众/平台语境 → 换皮后用
- 不可复制：名气/颜值/独家资源/人设经历 → 放弃，别假装能抄

## 2. 标签火力实证算法

**主算法（六步）**：

1. 中位赞：本批样本里有可见赞的中位数。
2. 爆款线：3 × 中位赞（爆款是相对量，不是绝对赞数）。
3. 爆款集合：爆款线以上的笔记/视频。
4. 标签归一：同义并账后逐条抽出。
5. 火力排序：单标签火力 = 它在爆款集合里的累计赞，降序。
6. 入库门槛：≥2 条爆款为「实证档」；1 条但赞高为「孤证档」。

**火力闸门**（与 SKILL.md ④段一致，细则）：
- 平台样本闸门：单平台有效样本 <20 条 → 整表标「观察级」，禁「实测最火」表述；提示补 3-5 个竞品名扩样，拒绝则交付挂「样本不足」徽章。
- 标签最小样本闸：主火力标签需小红书 ≥8 条含该标签笔记、抖音 ≥5 条视频；不够 → 只进「弱证据附录」，禁当第⑤段主钩子，交付物标「样本不足，不宣称火力实证」。
- 时间衰减：默认只计近 90 天互动；有按周粒度数据时按周指数衰减加权（本周权重 1.0，每往前一周乘衰减系数，如 0.9）。
- 离群封顶：单条赞 > 同池中位数 10 倍，按 10×中位数计入累计；话题累计赞若单条贡献 >70%，不得标「品类主火力」，只能标「单条爆款句式，可借结构不可借权重」。
- 最低门槛：标签累计赞 < 类目 2 倍中位赞 → 只进备选池。

**纪律**：只用 likes 比 likes；views 与 likes 不混算；缺赞记 null 不当 0；跨账号比较标注粉丝量与样本差。

**辅助算法（单篇热度，引 viral-note-agent-skill，MIT）**：需要对单篇排序时可用六维加权——搜索意图相关 0.32 + 搜索排名 0.25 + 新鲜度 0.18 + 跨引擎支持 0.15 + 来源置信 0.10，再叠 log 缩放、新鲜度衰减、创作者规模归一。注意：无授权互动数据时它只是公开索引分（0-100，公开口径下限约 62），别把它当真实赞数用。

## 4. 文案三公式

| 公式 | 结构 | 适用 | 数据位 |
|---|---|---|---|
| AIDA | 注意→兴趣→欲望→行动 | 种草长文（默认） | A=痛点钩子（火标签）；I=卖点+信任装置；D=仪式+实证；A=互动 CTA |
| PAS | 痛点→放大→解决 | 新品类教育、痛点尖锐 | P=人群痛点；A=不解决的后果（不过度恐吓）；S=产品+证据 |
| FAB | 特性→优势→利益 | 卖点直给、直转 | 每个卖点三连写；批量占比 ≤20% |

## 5. 10 切角矩阵与情绪温度

| 切角 | 开头钩子写法 | 默认情绪温度 |
|---|---|---|
| 痛点型 | 把用户的痛说具体（发缝能塞手指） | 冲突反问 |
| 反常识型 | 都说 X，其实 Y | 冲突反问 |
| 误区型 | 你还在用错误的方法做 X | 冲突反问 |
| 步骤型 | 3 步搞定 X | 冷静测评 |
| 对比型 | A 和 B 摆在一起 | 冷静测评 |
| 故事型 | 那天我…… | 冷静测评（叙事） |
| 场景代入型 | 当你……的时候 | 冷静测评（画面） |
| 清单型 | 这 5 个…… | 冷静测评 |
| 结果导向型 | 90 天后…… | 冷静测评（证据） |
| 强 CTA 型 | 别再 X 了，直接 Y | 紧迫感 |

情绪温度三档：冷静测评 / 紧迫感 / 冲突反问。每批产出 ≥3 种温度，同批不许切角同温（SKILL.md ⑤段闸一）。

每条文案四件套：切角名 / 开头钩子 / 主体 / 收尾 CTA。
批量差异化判准：条与条之间不许只换词——钩子、情境、痛点切角、说服顺序、CTA 至少换一样，否则整批作废重排。

## 6. 句式填空模板（从爆款抽象；只借骨架，实体词全换——洗稿判定见 SKILL.md 闸三）

- 你以为 ___，其实真正影响 ___ 的是 ___
- 很多人做 ___ 都卡在 ___，不是因为 ___，而是因为 ___
- 养发的尽头是 ___（断言句式，2029 赞实证）
- 别再乱买 ___ 了（避坑体，788 赞）
- ___ 是智商税吗？我把 ___（说真话体，1779+1512 赞）
- 发缝宽、___（痛点具象，9725 赞）
- 我去，也没人告诉我 ___（反转起手，抖音约 181.8 万赞）

空位填竞品属性卡字段（人群/场景/卖点/数字）。

注意：句式是否可用由主机制决定（见 SKILL.md ⑤主机制定结构）——竞品已用红的骨架（如卡诗带火的「养发的尽头是 X」）在自家主机制=成分昵称时禁再套；万能补丁黑名单（有图有真相/亲测有效/闭眼入/打工人必备）任何句式里都不许出现。

## 7. 批量配比与校准

- 配比：10 流量钩子 : 8 痛点种草 : 6 专业信任 : 4 产品需求 : 2 直接转化（30 条基准，等比缩放）。
- 强转化默认 ≤20%，用户明说投放模式才放开。
- 校准先行：先交 1 条样稿，用户点头再批量。
