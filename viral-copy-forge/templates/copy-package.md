# 模板：文案包（⑤⑥段产出）

## 空白骨架

```
### 标题主推（1 条：换品名测试分最高、且刺点类型与其余不同者；标切角/情绪温度/火标签/锚点；附四闸评分）
### 备选留档（≤2 条，用户点名要候选池才给）
### 正文（能原样复制发出的干净成稿：句中不夹任何括号批注，公式名和赞数一律写进证据行）
### 口播版（仅抖音：前 3 秒钩子单独写）
### 标签双池（小红书池 / 抖音池；主钩子标签必须过火力闸门，弱证据附录标签禁当主钩子）
### 证据行（表：文案位 → 写法拆解 → 几条爆款多少赞；指不回火力表来源的删）
### 合规警示（本品类具体红线 + Claim Ledger 状态）
### 闸门通过记录（用了哪些闸、哪些标签进弱证据附录、观察级/样本不足徽章）
### 数据缺口与丑话三句（单平台证据标注挂这里）
```

## Input 示例

产品卡：山屿折叠月亮椅（虚拟示范品，户外露营椅，1.4kg，199 元，承重 120kg）；火力表：断言句式〔赞数·占位〕、连载仪式〔赞数·占位〕、实证体〔赞数·占位〕、说真话体〔赞数·占位〕；竞品解剖：某大牌「一秒开合」卖点 + 开箱仪式。

## Output 示例

读前须知：示范品故意选了露营椅，和你手上的产品不同品类——这一页教的是**结构**，不是句子。方括号里写着「占位」的都不是数据，真实运行换成本轮火力表的数；示范句一句都不许搬进交付物，这段须知也不许抄。

### 标题主推

「1.4kg 的月亮椅，我背着它爬了 3 座山｜第几次坐下去才不想起来」
—— 断言句式（〔赞数·占位〕）+ 数字锚；锚点=1.4kg/3 座山；刺点=「背着爬山」（竞品只讲开合）；温度=冷静测评

四闸评分：①锚点刺点：1.4kg=锚，「背着爬山」=场景刺点 ✅ ②换品名：换成普通露营椅「1.4kg」不成立，句子塌 ✅ ③自评：钩子5/证据4/记忆点4/排他4=17/20 ✅ ④洗稿：实体词全换 ✅ → **交付评分最高版**
备选留档：「露营椅是智商税吗？我把 5 把椅子的重量表贴出来了」（温度=冲突反问，刺点类型=真数字对比）

### 正文（AIDA）

> 上次露营，折叠椅三斤多，走到营地肩膀勒出两道红印。
> 某大牌那把一秒开合确实快，可它塞不进我的登山包。
> 这把我是看了参数才下单的：1.4kg，收起来比保温杯粗一圈。
> 背着它走了 3 座山，每次都是同一个姿势坐下去就不想动。
> 三次营地的照片放在最后。
> 丑话说前面：它不适合 120kg 以上的朋友，这是它的承重线。
> 你露营最烦背的是哪样东西？

### 口播版（抖音，前 3 秒反转钩子）

> 「1.4kg 这个数，我在营地拿行李秤称了三次。」

接 3 座山实拍口播；写法拆解见证据行。

### 标签双池

- 小红书：#露营装备 #轻量化露营 #月亮椅 #徒步露营 #露营好物
- 抖音：#露营 #露营装备 #户外（泛词必挂池）+ #轻量化露营（副话题候选）

### 证据行

| 文案位 | 写法拆解 | 证据 |
|---|---|---|
| 标题 1 | 断言句式 + 数字锚 | 〔赞数·占位〕 |
| 正文首句 | 痛点具象（A） | 〔赞数·占位〕 |
| 正文第 3 句 | 背书换成可验的参数，不编专家（I） | 产品属性，指回产品卡 |
| 正文第 4–5 句 | 连载仪式 + 实证体（D） | 〔赞数·占位〕 |
| 结尾前一句 | 说真话体 | 〔赞数·占位〕 |
| 口播前 3 秒 | 反转起手 | 〔赞数·占位〕（抖音） |

### 合规警示

「某大牌」不点名；承重、重量只写产品卡给的数；「坐下去就不想动」是体感不是承诺；没有真实专家就不写专家，背书用参数这种可验的东西。

### 数据缺口与丑话三句

数据缺口：〔本轮真实缺口·占位：哪个平台没采到、哪列没日期、样本几条〕。丑话三句：标签只把起跑线提到 60 分；句式可借内容必须换皮；点赞不等于转化。
