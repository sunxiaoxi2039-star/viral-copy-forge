# 模板：文案包（⑤⑥段产出）

## 空白骨架

```
### 标题主推（1 条：换品名测试分最高、且刺点类型与其余不同者；标切角/情绪温度/火标签/锚点；附四闸评分）
### 备选留档（≤2 条，用户点名要候选池才给）
### 正文（标注公式名；句后括号标证据来源，发出前删标注）
### 口播版（仅抖音：前 3 秒钩子单独写）
### 标签双池（小红书池 / 抖音池；主钩子标签必须过火力闸门，弱证据附录标签禁当主钩子）
### 证据行（表：文案位 → 用了什么 → 几条爆款多少赞；指不回火力表来源的删）
### 合规警示（本品类具体红线 + Claim Ledger 状态）
### 闸门通过记录（用了哪些闸、哪些标签进弱证据附录、观察级/样本不足徽章）
### 数据缺口与丑话三句（单平台证据标注挂这里）
```

## Input 示例

产品卡：姜小满头皮精华（虚拟示范品，姜提取物+发热感，百元级）；火力表：断言句式〔赞数·占位〕、连载仪式〔赞数·占位〕、实证体〔赞数·占位〕、说真话体〔赞数·占位〕；竞品解剖：卡诗「元气姜」昵称 + 打卡仪式。

## Output 示例

### 标题主推

「养发的尽头是一瓶会发热的姜精华｜28 天打卡，对比图按周排」
—— 断言句式（〔赞数·占位〕）+ 连载仪式（〔赞数·占位〕）+ 数字锚；锚点=28天/按周排；刺点=「会发热」（体感，竞品无）；温度=冷静测评
（注：本页所有〔赞数·占位〕都是占位符，不是数据。真实运行必须换成本轮火力表算出来的数字；照抄占位符、照抄本页任何数字、或把本行注解一起抄进交付物，都算废稿重写。）

四闸评分：①锚点刺点：28天=锚，「会发热」=体感刺点 ✅ ②换品名：换成普通精华名「会发热」不成立，句子塌 ✅ ③自评：钩子5/证据4/记忆点4/排他4=17/20 ✅ ④洗稿：实体词全换 ✅ → **交付评分最高版**
备选留档：「防脱洗发水是智商税吗？我把成分表翻烂了，只留下这 1 瓶」（温度=冲突反问，刺点类型=真数字成分表）

### 正文（AIDA）

> 28 天前我的发缝能塞进一根手指（A，痛点具象〔赞数·占位〕句式）。
> 试过某大牌精华，打卡到 day8 实在心疼钱包（暗踩痛点：贵，不点名）。
> 学成分的朋友一句话点醒我：防脱看成分和坚持，不看广告（I，人格背书，规避虚构医背）。
> 姜小满头皮精华我用了 28 天，每周拍照，发缝肉眼变密（D，连载仪式+实证体）。
> 第 1 / 2 / 4 周对比图附上。
> 说句大实话：它不是生发水，严重脱发请直接看医生（说真话体 + 合规）。
> 你的发缝几年了？评论区报个数（A，复盘型互动钩子）。

### 口播版（抖音，前 3 秒反转钩子）

> 「我去，也没人告诉我，头皮养对了，换季根本不掉这么多啊？」——反转起手（〔赞数·占位〕句式实证），后接 28 天对比口播。

### 标签双池

- 小红书：#防脱洗发水 #头皮精华 #发缝宽 #发际线 #养发打卡 #细软油头
- 抖音：#防脱洗发水 #洗发水 #防脱（泛词必挂池）+ #养发打卡（副话题候选）

### 证据行

| 文案位 | 用了什么 | 证据 |
|---|---|---|
| 标题 1 | 断言句式 | 〔赞数·占位〕 |
| 正文首句 | 痛点具象 | 〔赞数·占位〕 |
| 结尾 | 说真话体 | 〔赞数·占位〕 |
| 口播前 3 秒 | 反转起手 | 〔赞数·占位〕（抖音） |

### 合规警示

不宣称生发（非特证）；「某大牌」不点名；医生表述已替换为「学成分的朋友」；「发热感」是使用体感不是疗效。

### 数据缺口与丑话三句

数据缺口：本例为教学示范，无真实采集。丑话三句：标签只把起跑线提到 60 分；句式可借内容必须换皮；点赞不等于转化。
