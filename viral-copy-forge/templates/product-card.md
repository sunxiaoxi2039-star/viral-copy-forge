# 模板：产品卡（①段产出）

## 空白骨架

| 项 | 值 |
|---|---|
| 产品名 | |
| 品类 | |
| 核心卖点（≤3） | |
| 人群 | |
| 价格带 | |
| 目标平台 | 小红书 / 抖音 / 双平台 |
| 投流目标 | 种草 / 直转 |
| 合规红线 | |
| 竞品（1-3 个） | |
| 必须避的坑 | |

缺字段处理：类目 / 平台 / 投流目标缺任一 → 停下来问用户；其余字段缺失 → 保守假设并标「假设」。医疗/功效/母婴/认证类此段就读 references/compliance.md。

## Input 示例

用户原话：「帮我给蔓迪防脱固发洗发水写小红书和抖音的文案，5% 米诺地尔，械字号，对家是达霏欣和卡诗。」

## Output 示例

| 项 | 值 |
|---|---|
| 产品名 | 蔓迪防脱固发洗发水 |
| 品类 | 防脱洗发水（功效类 → 合规强制模式） |
| 核心卖点 | 5% 米诺地尔；械字号批文；药企背书 |
| 人群 | 压力掉发的 25-40 岁打工人；发缝/发际线焦虑人群（假设，待确认） |
| 价格带 | 百元级（假设） |
| 目标平台 | 双平台 |
| 投流目标 | 种草为主 |
| 合规红线 | 不宣称生发；不对比未验证人群；背书须真实 |
| 竞品 | 达霏欣、卡诗 |
| 必须避的坑 | 智商税质疑；医疗化表述 |
